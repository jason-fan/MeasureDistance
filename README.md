# STM8S103F3P6 project5 — HC-SR04 超声波测距 + 2 位 7 段数码管显示 + UART 调试 + BEEP

本工程基于 **STM8S103F3P6（TSSOP20）**，采用 **SDCC** 编译，工程结构与编码风格与
`project4` 完全一致：面向对象封装（结构体 + 函数指针）、`main.c` 集中定义 ISR、
**TIM2 1ms 时间片**调度（TIM1 在本工程降为**纯 1us 时基、无中断**）、数码管动态
扫描、UART 调试输出。与 project4 的关键区别：

- **外设更换**：去掉 I2C（不再使用 PB4/PB5），新增 **HC-SR04 超声波测距**；
- **数码管更换**：四位共阴改为**两位共阳**（段码表取反为低电平点亮、位选高电平
  选中，位选只需 2 个）；
- **新增 BEEP**：复用 project1 的 `beep.c/beep.h`（硬件 BEEP 外设 PD4，LSI 时钟，
  1/2/4kHz），**两级报警：<10cm 每 2 次采纳读数短鸣 1 次（200ms 一次，~5Hz），
  10~20cm 每 4 次采纳读数短鸣 1 次（400ms 一次）**（≥20cm、无效 / 无回波不响）；
- **测量周期 100ms**：HC-SR04 推荐的最短周期；median3 + mean2 滤波在 100ms 采样下
  约 250ms 输出首个有效值、稳态滞后约 150ms；无回波时周期自动延长到 200/400ms
  （见 §4、§5.2）。

- MCU: STM8S103F3P6（TSSOP20）
- 时钟: HSI 16MHz（无外部晶振）
- 编译器: SDCC 4.5.0（`sdcc -mstm8 --std-c99`）
- 烧录: stm8flash（ST-LINK/V2）

## 1. 功能概述

| 功能 | 说明 |
|---|---|
| HC-SR04 测距 | PB5=Trig（开漏输出 + 外部 10k 上拉，**20us** 高脉冲触发），PB4=Echo（输入，高电平宽度 = 距离），**非阻塞状态机驱动**，测量周期 **100ms**（无回波时退避到 200/400ms） |
| 距离换算 | **毫米精度**：mm = Echo 高电平宽度(us) × 10 / 58（uint32 中间量防溢出），TIM1 1MHz 计数器（ARR=0xFFFF 自由运行）提供 1us 级测量 |
| 数码管显示 | 两位八段**共阳**数码管，显示量程上限 **1m**：≥10cm 且 <100cm 整数 cm（**个位带小数点 dp**，如 `12.`）、<10cm 带 1 位小数（点亮小数点 dp，如 `3.5` / `0.9`）、**≥1m 或无效时一律显示 `--`** |
| UART 调试 | UART1 115200 8N1（PD5=TX / PD6=RX），**变化驱动**输出（面板值变化 ≥5mm 或进出 `--` 才打印一行 `SHOW <面板文本> \| <mm>`，静止目标静默） |
| BEEP 提示 | 硬件 BEEP 外设（PD4，LSI 1/2/4kHz），**两级报警**：**<10cm 每 2 次采纳读数短鸣 1 次**（200ms 一次，~5Hz 急促）；**10~20cm 每 4 次采纳读数短鸣 1 次**（400ms 一次，2.5Hz）；均为 2kHz/50ms。**≥20cm（含 20cm~1m 的显示区间）、≥1m、无效/无回波一律不响** |

启动流程：初始化外设 -> 数码管显示 `--` -> 每 **100ms** 启动一次非阻塞测距（主循环
每轮调用 `service()` 推进状态机）-> 测量完成时更新显示 / 打印 UART / 播放提示音。

## 4. HC-SR04 测距原理与时序

HC-SR04 工作流程：

```
主控 (PB5)                 HC-SR04                   主控 (PB4)
  |-- Trig 高 >=10us ----->|                           |
  |                        |-- 发 8 个 40kHz 超声脉冲 ->| 障碍物
  |                        |<-- 回波 Echo 高电平 -------| 宽度 = 往返时间
  |-- 读 Echo 高电平宽度 ->|                           |
```

- **触发**：`Trig` 拉高 20us（数据手册要求 >=10us，代码给 20us 余量），随后拉低；
  本板 Trig 由 3.3V 开漏引脚驱动、依靠外部 10k 上拉，而 HC-SR04 输入门限约
  3.0~3.5V，3.3V 恰好卡在门限边缘，脉宽过短时传感器约有一半概率漏触发
  （表现为大量 `us=0`），因此把脉宽放宽到 20us 以穿越上拉上升沿与门限不确定性；
- **回波**：`Echo` 高电平持续时间与距离成正比，**内部精度为毫米：
  距离(mm) = 高电平时间(us) × 10 / 58**（先乘 10 再除 58，使用 uint32
  中间量防溢出）；显示与 UART 仍以 cm 为单位输出；
- **时基**：TIM1 预分频 /16（HSI 16MHz -> 1MHz 计数，1us 分辨率），**ARR=0xFFFF
  自由运行且关闭更新中断**（纯时基，CNTR 每 65.536ms 回绕，测宽只取两次 CNTR
  快照的 16 位差值，因此不再受 1ms 计数器上限约束）；**1ms 时间片改由 TIM2 更新
  中断（IRQ13）提供**，负责数码管动态扫描、BEEP 计时与 `g_tick` 调度。距离计算
  完全来自 TIM1 CNTR，与 `g_tick` 无关——`g_tick` 只做调度，不参与测距；
- **有效性**：回波宽度 134us（约 2.3cm）~ 6000us（约 103cm，
  `HCSR04_MAX_US = HCSR04_CAPTURE_US = 6000UL`）判定为有效，其余为超量程/无效；
  每 **100ms** 启动一次测量，无回波时周期按退避策略延长（见下）。
  **< 134us（约 2.3cm 以下）落在 HC-SR04 声学盲区内、实测不准，一律判无效**：
  显示两位横杠 `--`、不蜂鸣、UART 打印 `SHOW -- cm | NOECHO`。
  注意区分两个「量程」：**传感器有效量程约 2.3cm~103cm**（决定 `valid`），
  **显示量程上限为 1m**（`valid` 但 ≥1000mm 时显示 `--`，UART 打印
  `SHOW -- cm | OVR`，见第 5、7 节），**蜂鸣只在 <20cm 触发，其中 <10cm 升级为
  每 2 次采纳响 1 次**（见第 6 节）。
- **失败自动重试**：一个 **100ms** 周期内，若某次尝试结果无效（`valid==0` 或
  `last_echo_us==0`），间隔 **`HCSR04_RETRY_GAP_MS` = 20ms** 后自动重新 `start()`，
  最多重试 **`HCSR04_RETRY_MAX` = 2 次**（每周期最多 3 次尝试），任一次成功即停止
  重试；重试计数与间隔均基于 `g_tick`，不阻塞主循环；3 次全失败才显示 `--` 且不
  蜂鸣。失败尝试不会立即刷新显示/串口，只有最终结果（成功或 3 次全败）才上报。
- **无回波退避**：整周期彻底无回波时 `idle_backoff` 逐级 +1，测量周期变为
  **100 / 200 / 400ms**（`HCSR04_PERIOD_MS << idle_backoff`，上限 4×）。原因是
  一次失败捕获会把全局中断屏蔽满 6.0ms，占 100ms 周期的 6%，连续失败会让 `--`
  屏闪动；退避到 400ms 后同样 6.0ms 只占 1.5%。任一有效读数立即回到 100ms。
- **非阻塞状态机**：`start()` 发起一次测量（仅空闲 / 上次结果已消费时接受）；
  `service()` 由主循环每轮调用一次，状态机依次推进「等待 Echo 空闲 -> 触发
  20us 脉冲 -> 等待 Echo 高 -> 等待 Echo 低 -> 下降沿去抖确认 -> 计算距离」，
  各等待均以 TIM1 微秒时钟做超时保护（空闲 5ms / **回波 8ms** / 下降沿 40ms，
  见 `HCSR04_WAIT_IDLE_US` / `HCSR04_WAIT_HIGH_US` / `HCSR04_WAIT_LOW_US`），
  除 20us 触发脉冲忙等外不阻塞主循环；返回 `HCSR04_DONE` 表示本次完成，结果存于
  `valid` / `last_dist_mm`（毫米）。
- **捕获窗口与数码管消隐（`blank_cb`）**：从触发到回波下降沿的整个脉冲捕获过程
  会**关闭全局中断**，以保证边沿时间戳不被中断延迟污染；该窗口最长
  **6.0ms**（`HCSR04_CAPTURE_US`，60~70cm 实测约 4ms，无回波时直接到上限）。
  窗口内 TIM2 的 1ms 扫描中断无法运行，若不做处理会出现「一位常亮、另一位熄灭」
  的单侧亮度错误（在 10Hz 节奏上肉眼看着就是"扫描卡住"）。因此 `main.c` 把
  `hcsr04.blank_cb` 绑定到 `seg_blank_all()`：关中断**之前**把两位位选同时拉低，
  冻结窗口只表现为整屏轻微变暗，而不是单侧常亮。
- **Echo 下降沿去抖确认（200us 窗口）**：`WAIT_LOW` 首次采到低电平不直接当作
  下降沿，只把该时刻记为**候选** `t1` 并进入 `WAIT_CONFIRM`；`HCSR04_CONFIRM_US`
  = 200us 后重采样，仍为低才确认是真实下降沿，若已回到高则判为毛刺丢弃并退回
  `WAIT_LOW` 继续等待真正下降沿。真实下降沿之后 Echo 会持续低电平数毫秒（直到
  下一个 100ms 触发），因此 200us 窗口不会误伤真沿；而远端测距时叠加在宽回波
  上的短时低电平干扰无法维持 200us，会被滤除。测宽仍使用**候选时刻** `t1` 与上升
  沿 `t0` 之差，确认延迟不引入误差。确认态同时设时间条件与重试上限
  （`HCSR04_CONFIRM_MAX_RETRY` = 1500 次 `service()` 调用，仅在微秒时钟停摆时
  兜底），200us 窗口正常只需约 40~70 次调用，上限不会提前截断窗口。

## 5. 数码管显示策略

两位八段**共阳**数码管实时显示最近一次测距结果（内部毫米精度，显示换算为 cm）：

| 测量结果 | 显示 |
|---|---|
| 有效且 ≥ 100mm 且 < 1000mm（≥10cm，<1m） | 整数 cm，**四舍五入到最近 cm**：十位 = r/100（**不带 dp**）、个位 = (r/10)%10 **并点亮小数点 dp**，其中 `r = mm + 5`（如 123mm→`12.`、148mm→`15.`、996mm→`99.`，不进位成 `100`） |
| 有效且 < 100mm（2.3cm ~ 9.9cm） | 带 1 位小数的 cm：十位 = mm/10 **并点亮小数点 dp**、个位 = mm%10（如 35mm→`3.5`、23mm→`2.3`） |
| 有效且 ≥ 1000mm（≥1m） | `--`（**超出显示量程**：两位都显示横杠、不带 dp，与无效读数外观一致；真实测距值仍通过 UART 打印） |
| 回波宽度 < 134us（< 约 2.3cm，盲区内） | `--`（按无效处理，不蜂鸣，UART 打印 `SHOW -- cm \| NOECHO`） |
| 无效 / 无回波 / 超时 | `--` |

- 小数点段 dp（PC7）仅在**有效且 <1m** 的显示中被点亮：<10cm 时点亮十位
  （`mm/10` 带 `SEG_FLAG_DP`，显示 `x.x`）；≥10cm 且 <100cm 时点亮个位
  （`(mm/10)%10` 带 `SEG_FLAG_DP`，显示 `xx.`）；**≥1m 与无效 / 无回波显示
  `--`，均不带小数点**；
- 段码表为共阴表的按位取反（低电平点亮），位选高电平选中（与 project4 相反）；
- 动态扫描：**TIM2 1ms ISR** 中 `seg.onTime()` 每 1ms 点亮一位，2ms 一轮全刷新
  （约 500Hz/位，无闪烁）；HC-SR04 捕获窗口内该 ISR 被中断屏蔽暂停，靠
  `blank_cb` 消隐整屏（见 §4）；
- 显示缓冲在 main 循环更新，段/位实际输出在 ISR 完成（非阻塞）。

### 5.1 距离跳变抑制（**当前未启用**）

`dist_filter()`（`HCSR04_JUMP_THRESHOLD_MM` = 300mm 跳变阈值 +
`HCSR04_PENDING_MAX` = 3 个待确认周期）仍保留在 `main.c` 中，但**处理链已不再
调用它**——它会把真实缓慢靠近判为"未确认跳变"并压住读数若干周期，随后一次跳
好几格，观感比偶尔的尖峰更差。尖峰改由 §5.2 的中位数窗口负责。

现役处理顺序（`hcsr04_handle_done()`）：

```
原始读数 mm -> ① 量程检查(>=1000mm -> "--" 并清空滤波窗口)
            -> ② median3 -> ③ mean2 -> ④ 最近 5mm 取整 -> 显示 / UART / 蜂鸣
```

量程检查**先于**滤波是最关键的一步：若放到滤波之后，一个合法的远处读数（如
125cm，对比陈旧的 4390mm 参考值）会被判定为"未确认跳变"，从而以普通 cm 值打印，
与"≥1m 显示 `--`"的规则自相矛盾。超量程读数也不会污染下一次在量程内的参考值。

### 5.2 中位数 + 均值滤波

有效读数依次经过两级滑动窗口，最后量化到 5mm 网格（`hcsr04_handle_done()`）：

1. **3 点滑动中位数**（`median_push()`，窗口 `HCSR04_MEDIAN_WIN` = **3**）：
   剔除单周期孤立尖峰（上一周期残留回波、电磁干扰引起的单点跳变）。用 5 点
   窗口时目标缓慢靠近会被压住 2 个周期，故定为 3；
2. **2 点滑动均值**（`mean_push()`，窗口 `HCSR04_MEAN_WIN` = **2**）：削掉中位数
   剩下的抖动；
3. **最近 5mm 取整**：`((avg + 2) / 5) * 5`，对齐显示网格（10cm 以上整 cm、
   10cm 以下 0.5cm）。

顺序不可调换：尖峰必须先消失，否则会污染均值；均值必须先成形，否则 5mm 网格
只会把抖动换个尺寸继续传递。

- 采样周期 100ms，故**首次有效输出约 250ms**（median3 需 3 拍 + mean2 约 50ms
  中心滞后），**稳态滞后约 150ms**——这是仍能抑制单次坏回波的最短链路；
- 窗口首次填满前的读数按已有样本数计算，不做额外等待；
- 超量程（≥1000mm）与无效分支都会调用 `median_reset()` / `mean_reset()` 清空
  窗口，重回正常范围时首读直接采纳，避免旧样本拖动新读数。

### 5.3 显示滞回（**当前未启用**）

`display_update()` 与 `HCSR04_DISPLAY_HYST_MM`（10mm，一个最低显示位）同样保留
但不再参与显示路径：滤波链输出直接送面板，滞回被判为多余——10mm 滞回与「缓慢
靠近时读数不动、随后跨窗跳两格」的台阶感直接相关。

- 若将来要恢复：滞回必须 ≤ 1cm（一个显示步进），否则 10mm 内的差值不刷新面板；
- 与 §5 的四舍五入配合时，面板值与真实值偏差应始终 < 5mm + 半格；
- 现在面板稳定性由 median3 + mean2 + 5mm 量化共同保证，不依赖滞回；
- 若环境噪声明显变大，优先把 `HCSR04_DISPLAY_HYST_MM` 调到 20~30 并重新接入
  `display_update()`，以"台阶跟随"换面板稳定。

## 6. BEEP 提示音

复用 project1 的 `beep.c/beep.h`：硬件 BEEP 外设（PD4），时钟源为内部 LSI
（128kHz），`BEEPDIV` 分频到 ~8kHz 后由 `BEEPSEL` 选择 1/2/4kHz 输出。
`beep.update()` 集成在 **TIM2 1ms 时间片**（自动关断定时）。

单个测量周期只有 100ms，因此两档都必须按「采纳读数次数」节流——每周期都响就是
10Hz，50ms 的脉冲会连成一片柔和的连续音，听不出是"滴"：

| 场景 | 提示音 |
|---|---|
| 采纳的有效读数 < 100mm（<10cm） | **紧急档：每 2 次采纳读数短鸣 1 次**（`HCSR04_CRIT_BEEP_EVERY` = 2，200ms 一次，~5Hz），2kHz / 50ms；近距档计数器被钉在 0 |
| 采纳的有效读数 100~200mm（10~20cm） | 2kHz / 50ms 短鸣，**每 4 次采纳读数才响 1 次**（`HCSR04_NEAR_BEEP_EVERY` = 4，400ms 一次，2.5Hz），响后计数器清零 |
| 采纳的有效读数 ≥ 200mm（含 20cm~1m 的显示区间） | 不响，并**清零两档计数器** |
| 有效但 ≥1000mm（超出显示量程） | 不响，清零两档计数器 |
| 无效 / 无回波 / 超时 | 不响，清零两档计数器，并丢弃滤波窗口与面板值 |

> 蜂鸣采用**两级升档**，凭听感即可判断距离：<10cm 是 200ms 一次的急促报警
> （~5Hz），10~20cm 是 400ms 一次的提醒；两档响度与频率相同，只靠节奏区分，
> 避免为了区分而额外调频。
> 蜂鸣范围（<20cm）比显示范围（<1m）更窄：20cm~1m 只显示数值、不鸣叫，避免中
> 距离持续响。两档各有独立计数器，且一旦离开本档或读数转无效就清零，因此
> 「半满的 2.5Hz 计数」绝不会被 5Hz 报警档继承，残留计数也不会在下次靠近时提前
> 触发。`HCSR04_CRIT_MM`（100）、`HCSR04_NEAR_MM`（200）、
> `HCSR04_CRIT_BEEP_EVERY`（2）、`HCSR04_NEAR_BEEP_EVERY`（4）均在 `main.c`
> 顶部可改。

## 7. UART 输出示例

上电横幅（4 行，每行打印后立即 `tx_service()` 冲刷——TX 环形缓冲仅 127 字节，
4 行合计超限，不冲刷会截断成半句）：

```

Trig=PB5 Echo=PB4, 100ms period, retry x2, mm in / cm out
Filter: median3 -> mean2 -> round 5mm. Timebase: TIM1 1us, TIM2 1ms
Log: one line per >=5mm change: SHOW <panel> | <mm>
```

运行日志：**变化驱动**，面板值相对上一行变化 ≥ `HCSR04_UART_CHG_MM`（5mm）才打印
一行；进入 `--` 状态时只在该状态"首次到达"时打一行（不刷屏）。字段含义：
前半是**面板文本**（与两位数码管逐字对应，可肉眼核对），后半是**内部毫米值**
（median/mean/5mm 量化之后，不再取整，所以 `SHOW 42 cm | 421 mm` 展示的是面板
把 421mm 截成 `42.`）：

```
SHOW 42 cm | 421 mm        (>=10cm: 整数 cm，个位带 dp -> 面板 "42.")
SHOW 3.5 cm | 35 mm        (<10cm: 一位小数 -> 面板 "3.5")
SHOW 2.3 cm | 23 mm        (有效下限 134us，再短即判无效)
SHOW -- cm | OVR           (>=1000mm: 超出显示量程，显示 "--"，不蜂鸣)
SHOW -- cm | NOECHO        (盲区 us<134 / 无回波 / 3 次尝试全失败)
```

```

                                             # g_tick 为 uint16，65.536s 回绕，
                                             # 只看 +delta 是否 ~5000
SCAN per=998..1002 us, isr=36 us, mask=2400 us   # TEMP DIAG，每 2s 一行：
                                             # TIM2 ISR 间隔 / ISR 执行时长 /
                                             # 最长关中断捕获窗口(us)
```

`TICK` 默认关闭（`HCSR04_UART_TICK = 0`）；`SCAN` 是排查"数码管发暗/闪烁"时的
